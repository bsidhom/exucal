# Exucal

Exucal is a calculator in the browser that offers the elementary
functions and some special functions, and that keeps track of units
through every calculation and conversion. For arithmetic and functions
alike, it guarantees that a result is exact wherever it can be, and
that a result shortened for display shows only certified digits, with
the last correctly rounded, unless a note beside it says how many of
its digits are certified. The user's documentation is in
[`docs/`](docs/README.md), starting with a tour by example. The
developer's documentation is in [`devdocs/`](devdocs/README.md),
including how to build, run and test the app.
