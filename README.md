# Exucal

Exucal is a calculator that runs in the browser, computes exactly
wherever it can or else shows only the digits it has certified, brings
the elementary functions and the special functions that matter most in
combinatorics, probability and physics under that same guarantee, and
keeps track of units through every calculation and conversion. The
user's documentation is in [`docs/`](docs/README.md), starting with a
tour by example. The developer's documentation is in
[`devdocs/`](devdocs/README.md), including how to build, run and test
the app.
