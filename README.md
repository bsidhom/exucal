# Exucal

Exucal is a calculator in the browser that makes one guarantee for
its arithmetic and its functions alike, that it computes exactly
wherever it can or else shows only the digits it has certified; it
offers the elementary functions and some special functions, and it
keeps track of units through every calculation and conversion. The
user's documentation is in [`docs/`](docs/README.md), starting with a
tour by example. The developer's documentation is in
[`devdocs/`](devdocs/README.md), including how to build, run and test
the app.
