# The system unit definitions: every unit the app knows, defined in terms of
# others down to the primitives. README.md ("Unit definitions") describes
# the format, how names and expressions are read, what this file covers and
# how to add to it. Two reminders from there that matter most when editing:
#
#   - Juxtaposition binds tighter than `/`, so `1/12 year` is a frequency;
#     write `year / 12`.
#   - A name that reads as two different prefix-unit pairs fails the build,
#     which is why `u` (dalton) and `at` (technical atmosphere) are absent;
#     see `au` below.
#
# Where a factor is not obvious, a comment says where it comes from.

# Temperature intervals. A degree Celsius is the same size as a kelvin, and
# a degree Fahrenheit or Rankine is five ninths of one. These convert
# temperature differences; a temperature reading is converted through the
# functions below.

degC        K
celsius     degC
degF        5 K / 9
fahrenheit  degF
degR        degF
rankine     degR

# Temperature readings, as functions of a plain number: `tempC(100)` is the
# boiling point of water as a temperature in kelvin, and `tempF(212)` into
# `tempC` is `tempC(100)`. The declaration `[1;K]` says the argument is a
# plain number and the result a temperature; the body after it gives the
# reading, and the body after the `;` recovers the number from a reading.

tempC(x)    [1;K]  x K + 273.15 K       ; tempC / K - 273.15
tempF(x)    [1;K]  (x + 459.67) degF    ; tempF / degF - 459.67

# Logarithmic units, as functions of a plain number too, since a level is
# not a multiple of a unit but the logarithm of a ratio: `decibel(20)` is
# a power ratio of 100, `bel(2)` is the same ratio, and `neper(1)` is the
# amplitude ratio e. A ratio converts back into the level as into any
# function: `1000` into `decibel` is `decibel(30)`. The declaration `[1;1]`
# says the level and the ratio are both plain numbers, and the bodies call
# the built-in functions `pow`, `log10`, `exp` and `ln` (README.md,
# "Functions in expressions"). `dB` is deliberately absent: it reads as `d`
# + `B`, a tenth of a byte, and a function's name may not read as a prefix
# followed by a unit, the rule that keeps `u` and `at` out of this file.

neper(x)    [1;1]  exp(x)               ; ln(neper)
bel(x)      [1;1]  pow(10, x)           ; log10(bel)
decibel(x)  [1;1]  pow(10, x / 10)      ; 10 log10(decibel)
